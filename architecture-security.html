Architecture & Security

Salesforce-native, bounded and explainable.

Security Observatory separates experience, orchestration, collection, evidence and governance so every trust boundary remains visible and testable.

Architecture principles

  • In-org runtimeScanning, evidence and review stay inside Salesforce.
  • Read-only firstNo security remediation or production write-back.
  • Least privilegeSubscriber-owned authentication and permission-gated controls.
  • Truthful limitationsUnavailable evidence remains visible and explained.
