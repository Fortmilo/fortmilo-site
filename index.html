What is included

Baseline visibility included

  • Health Check configuration evidence
  • Connected Applications and OAuth exposure
  • Users, login recency, sessions and failed-login evidence
  • API-enabled access and selected privileged or data-exposure permissions
  • Licence capacity and bounded assignment evidence
  • Certificates, Sites and Experience Cloud baseline exposure
  • Sensitive administrative changes

Coverage is limited to supported evidence sources and is not comprehensive.

Connected review context

Where Security Observatory goes deeper

  1. Application governance from observed evidence.
  2. OAuth exposure correlated to supported users and applications.
  3. Named and External Credentials, endpoints, certificates, Sites and Experience Cloud evidence.
  4. Licence and selected privileged-access evidence.
  5. Source provenance, completeness, bounded interpretation and no-false-zero handling.

Evidence boundary

How your evidence is handled

  • Assessment is read-only and advisory.
  • Retained evidence is sanitised and linked to source provenance.
  • Unavailable, incomplete and not-retained states remain explicit.
  • An unavailable source is never presented as a zero result.
  • Evidence is retained in the subscriber Salesforce organisation.
  • Browser-prepared CSV downloads create a separate boundary outside Salesforce.

Questions to bring into focus

Review the exposure behind the headline count

  • Which applications can access the org?
  • Who still holds OAuth access?
  • Which inactive users retain exposure?
  • Which credentials and external endpoints exist?
  • Who owns each integration, and when was it last reviewed?
  • Where are selected powerful permissions assigned?
  • Which licences are being consumed?
  • Which evidence sources were incomplete or unavailable?
  • What evidence supports each conclusion?

Why the Observatory

Why Security Observatory?

Supported signals are brought together, exposure is correlated and safe review context is retained, while every conclusion remains bounded by the evidence that was actually available.

Designed to complement Salesforce's native security capabilities, not replace them.
