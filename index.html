Evidence before assumptions.

FortMilo Lab develops practical, read-only and evidence-focused tooling that helps organisations understand and govern their Salesforce security posture.

Security Observatory

The Salesforce Security Observatory is currently in development and private validation. It is designed to bring relevant security evidence into one controlled view without automatically changing the Salesforce organisation.

Read-only first

No automatic access removal, token revocation, endpoint changes or other remediation actions.

Explainable evidence

Findings are intended to distinguish observed evidence, inferred risk and unavailable evidence.

Salesforce-native

Built around Apex, Lightning Web Components, Tooling API access and secure Named Credential patterns.
