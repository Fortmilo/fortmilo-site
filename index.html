Independent Salesforce security engineering

Evidence before assumptions.

FortMilo Lab develops practical Salesforce security tooling that keeps evidence inside the organisation and leaves security decisions with the people accountable for them.

Explore the Observatory Contact FortMilo Lab

Operating principles

A narrow security boundary

Read-only

No security write-back

No token revocation, permission removal, API blocking, endpoint change or automatic remediation.

No data egress

Evidence remains in Salesforce

Scanning and retained evidence stay inside the subscriber organisation. Nothing is transmitted to FortMilo Lab.

Sanitised evidence

No attacker-useful values

No access tokens, session IDs, client secrets, certificate bodies, private keys or raw sensitive values.

Sandbox-first

Proof before release claims

Public installation and package support are stated only after the required clean-org and release evidence exists.

Salesforce Security Observatory

Read-only Salesforce security evidence

The Observatory is a Salesforce-native application built with Lightning Web Components, Apex orchestration, scanner classes, platform reads and sanitised in-org evidence.

It supports OAuth and integration review, findings triage, Security Benchmark for Salesforce control-identifier mapping, evidence coverage, safe export and bounded operational review without presenting itself as a compliance engine.
