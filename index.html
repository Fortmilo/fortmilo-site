FortMilo Lab

Salesforce architecture with a security-first boundary

FortMilo Lab is an independent software and security engineering practice founded by Salesforce architect Luca Pacini.

The work focuses on Salesforce platform security, identity, permissions, OAuth governance, integrations, evidence quality and secure delivery patterns.

Salesforce Security Observatory

A native evidence layer for security review

The Observatory uses Lightning Web Components, Apex, safe SOQL and Tooling API reads, and in-org storage of sanitised evidence. It is designed to help operators answer what needs attention, what evidence supports it and where to verify it in Salesforce.

Operating principles

Bounded by evidence and least privilege

No automated remediation

No token revocation, API blocking, permission removal, endpoint changes or production security write-back.

No attacker-useful evidence

No access tokens, session IDs, client secrets, certificate bodies, private keys or raw sensitive values.

No false clean

Unavailable or blocked evidence is shown as not assessed with a reason and safe next action.
