Architecture and security

Runs inside Salesforce with a narrow evidence boundary.

FortMilo Security Observatory is a Salesforce-native architecture showcase built around LWC, Apex orchestration, scanner classes, safe platform reads and sanitised in-org evidence.

Architecture boundaries

  • Salesforce-nativeLWC dashboard, Apex services and Salesforce data storage.
  • Read-only scanningSOQL, Tooling API and safe metadata reads.
  • Subscriber-owned authenticationManual self-callout configuration remains controlled by the installing organisation.
  • Truthful degradationMissing Tooling access becomes Not assessed, never a false zero.

Security boundaries

What the application deliberately does not do

No remediation

No token revocation, API blocking, permission removal, endpoint change, certificate rotation or production security write-back.

No secrets or raw credentials

No access tokens, refresh tokens, session IDs, client secrets, certificate bodies, private keys, raw headers or raw IP values.

No external evidence service

Scanning and retained evidence remain in the subscriber Salesforce organisation. The self-callout targets the same organisation’s Tooling API.

Self-callout prerequisite

Manual subscriber-owned authentication

Core SOQL-backed evidence works without the Tooling API self-callout. Tooling-backed scanner families require subscriber-specific authentication through an Auth Provider, External Client App, External Credential, Named Credential and principal.

The package does not own or overwrite subscriber OAuth configuration. A separate least-privilege permission extension may be deployed only after the named principal exists.

External Client App inventory is not claimed.
The current External Client App references describe the subscriber-owned self-callout prerequisite and principal context only.

Release boundary

Public source is curated, not mirrored

The private implementation and working history are not exposed directly. The future public application repository will contain selected sanitised source, architecture, setup guidance, synthetic evidence and contribution material.

Package distribution, clean-install proof and public availability are stated only when supporting evidence exists. The current position remains sandbox-first.
