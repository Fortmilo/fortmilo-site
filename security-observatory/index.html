Salesforce security evidence organised for review.

A sandbox-first, read-only application for posture evidence, safe drill-down and transparent limits across five focused areas.

Product boundaries

  • Runs inside SalesforceLWC, Apex, bounded SOQL and Tooling API reads, and in-org evidence objects.
  • Read-only and advisoryNo token revocation, permission removal, API blocking or endpoint changes.
  • Sanitised evidence onlyNo raw credentials, session values, certificate bodies or raw IP values.
  • Truthful availabilityUnavailable evidence is shown as Not assessed — reason.
