Overview hierarchy

OAuth-first by design

The Overview leads with OAuth grants requiring review. A retained authorisation record is not described as a live or usable credential, and the Observatory never tests a credential by attempting to use it.

PrimaryOAuth authorisation evidence and inactive or frozen-user association where retained evidence supports it.
Supporting orderSubscriber-owned External Client App principal context, Named and External Credentials, Sites and external surfaces, then Privileged Access Evidence.
Supporting evidenceHealth Check remains scoreless under SBS & Evidence. Package evidence is labelled Package Licence Capacity.
Truthful gapsUnavailable scanner evidence is shown as “Not assessed — reason” with a safe next action.

Native complement

Add evidence value rather than copy native views

Salesforce provides Security Center Essentials in Enterprise, Unlimited and Performance Editions for baseline configuration monitoring.

FortMilo Security Observatory is positioned around OAuth evidence passports, compound context, safe drill-down, benchmark coverage and like-for-like retained comparison rather than duplicating native headline views.
