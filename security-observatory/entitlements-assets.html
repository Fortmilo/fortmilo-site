Entitlements & Assets

Review licence use, assignment context and the applications it supports.

Review licence capacity, bounded assignment context and selected privileged access alongside governed application records, without changing access or commercial assignments.

Contained evidence

  • Governed applicationsDurable ownership, purpose and review context from supported observed evidence.
  • Licence capacityPackage, Permission Set and Salesforce User Licence evidence where available.
  • Assignment contextBounded retained identities and available assignment-source attribution.
  • Privileged accessSelected powerful permissions and assignment-source context.

Governed asset context

Connect entitlements to accountable application records

Retain durable governed application records from supported observed evidence, then add business and technical ownership, vendor, purpose, review status and review context when known. Source provenance and linked findings keep that context traceable.

Application context

Review the application or integration record alongside the access and licence evidence that supports it.

Assignment source

Show available attribution through Profile, Permission Set or Permission Set Group.

Selected privileged access

Review supported powerful permissions without presenting generic permission totals as the product's central proposition.

Licence posture

Keep capacity and bounded assignment evidence distinct

Review Package, Permission Set and Salesforce User Licence evidence without inventing cost or treating retained assignment detail as an organisation total.

Package Licences

Package Licence capacity evidence is available for managed packages that expose a Salesforce PackageLicense record. This is not a complete installed-package inventory.

Permission Set Licences

Review capacity, holdings and bounded assignment evidence where retained.

Salesforce User Licences

Review user licence totals, usage and remaining capacity with source context.

Evidence boundary

Detailed capture semantics live with the evidence contract

Licence-assignment detail varies by evidence level and can be bounded or incomplete. Zero retained rows must not be interpreted as zero assignments.

Review Evidence & Coverage for Top Issues, Balanced and Everything behaviour, per-family limits, transaction/DML headroom and capture-status semantics. The asset and governance CSV does not export the complete governance record.
