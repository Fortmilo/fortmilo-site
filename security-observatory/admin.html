Admin

Safe controls around one complete scan plan.

The Admin session manages evidence depth, bounded retention, scheduled execution and recovery of stale Observatory scan state. It does not manage Salesforce security remediation.

Evidence levels

Depth, not scanner selection

Every manual, scheduled and supported API-triggered scan uses the same Apex-owned scanner plan. Evidence level changes what is retained, displayed, compared and exported.

  • Top IssuesRetains and displays the highest-value evidence.
  • BalancedAdds safe drill-down evidence to the top-issue view.
  • EverythingRetains full-detail evidence and therefore uses the most storage.

Scan operations

Manual and scheduled execution share the same path

One Scan action

Client code does not own a second scanner list. Normal supported triggers invoke the same Apex-owned scan plan.

Scheduled scans

Admin-managed scheduling is disabled by default, uses fixed Weekly or Monthly presets and prevents overlapping scans. No free-form CRON input is exposed.

Visible execution status

The Admin surface shows schedule state, next run, last run and last result using bounded sanitised status.

Public-install qualification. Admin-managed scheduled scans are implemented in the current package source. Support through the public installation path remains subject to clean-org installation proof.

Retention

Bounded completed-scan history

Administrators can select a completed-scan retention limit from 1 to 10, with bounded defaults and a tighter Developer Edition rule for Everything evidence.

Old detail, metric and finding evidence is removed before the parent scan record. Failed, queued or running scans are not treated as completed clean baselines.

Recovery and registry

Operational recovery without remediation

Stale scan-lock recovery

An authorised administrator can close a confirmed orphan Queued or Running scan to a bounded Failed state when no active scan-lifecycle job remains.

No active-job cancellation

Recent, active or ambiguous scan locks remain protected. The UI does not expose raw scan IDs or AsyncApexJob IDs.

SBS registry controls

Bundled local SBS metadata can be managed through controlled administrator upload without internet update checks or automatic remapping.

Permission boundary

Admin-only and still read-only

Configuration and recovery controls are permission gated. They govern Observatory execution and evidence storage only; they do not revoke tokens, remove permissions, block APIs or alter endpoints.
